Objetivo del proyecto

Este proyecto es una práctica académica para aprender sobre participación juvenil, transparencia, control ciudadano y trazabilidad

Advertencia

Este es un proyecto en desarrollo y no refleja necesariamente la visión final del producto. Este sistema no corresponde a una elección real y no debe usar datos personales reales.

Clase 26 - 21 de mayo de 2026

En esta clase se presento el proyecto y se discutirán los objetivos y el alcance del mismo. Se explicará la importancia de la participación juvenil, la transparencia, el control ciudadano y la trazabilidad en el contexto de la democracia y la gobernanza. a nivel tecnico se creo el proyecto iniciando con el repositorio en GitHub y se establecieron las bases para el desarrollo del sistema, incluyendo la estructura del proyecto, las tecnologías a utilizar y los roles de los participantes.
