# Plataforma Juvenil de Participación

Proyecto académico para explorar cómo la tecnología puede apoyar ejercicios pedagógicos de participación juvenil, transparencia, control ciudadano y trazabilidad.

## Objetivo

Aprender y practicar técnicas y herramientas que permitan diseñar y prototipar una plataforma educativa orientada a la participación juvenil y la transparencia en procesos cívicos (uso exclusivamente académico).

## Advertencia

Este repositorio y los contenidos del proyecto son únicamente de carácter académico. No corresponde a una elección real y no debe:

- Recolectar datos personales reales.
- Usarse para campañas reales.
- Utilizarse para señalar personas, organizaciones o entidades.

## Cómo contribuir

1. Hacer fork de este repositorio.
2. Crear una rama para tu trabajo (por ejemplo `feature/nombre-apellido`).
3. Realizar cambios y abrir un pull request hacia la rama principal de tu fork.

## Evidencia y entrega

Cada estudiante debe trabajar desde su propio fork y publicar avances en una rama de trabajo; incluir en los commits y PRs notas claras sobre qué se avanzó en cada sesión.
